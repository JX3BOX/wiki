# 成就百科业务约定

## 关联成就展示

关联成就面板只在存在关联成就或存在 BOSS/NPC 参考数据时展示。请求失败属于辅助信息不可用，不应占用详情页空间，也不向用户显示“数据加载异常”。

| `relations` 状态 | 无 NPC 数据 | 有 NPC 数据 |
| --- | --- | --- |
| `null` | 不显示面板 | 显示 NPC 内容 |
| `false` | 静默，不显示面板 | 仅显示 NPC 内容 |
| `[]` | 不显示面板 | 显示 NPC 内容 |
| 非空数组 | 显示关联成就 | 同时显示关联成就和 NPC 内容 |

实现约束：

- 外层显隐条件保持为“关联成就数组非空，或存在 `npc`”。
- 请求失败可以继续用 `relations = false` 记录内部状态，但不得把 `relations === false` 加回外层显隐条件。
- 失败态不渲染 `ui.common.status.loadFailed`。
- 不修改关联成就和 BOSS 信息的 service、请求参数或成功数据结构。

实现位置：`src/components/cj/relations.vue`。

回归测试：`tests/reachable-async-regressions.test.js`。

## 功能等价要求

成就角色选择、完成状态、批量操作、侧栏筛选和方案加入行为均以线上实现为准。代码清理不得改变：

- 当前角色的对象或 `null` 数据契约。
- 完成、待完成状态的切换条件。
- 分类树、地图和角色筛选的值。
- 操作成功提示的触发时机。

移动端文案转入 i18n 后，简中仍必须保留原有措辞，例如“设为已完成”“确认”和“查看历史修订”。

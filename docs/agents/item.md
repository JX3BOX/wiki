# 物品百科业务约定

## 价格格式化

`src/utils/item-price.js` 是物品价格拆分与展示的唯一实现，`src/filters/item-price.js` 只负责复用并导出该实现，不再维护第二套计算逻辑。

价格继续按原有 `parseInt` 语义拆分：

- 1 砖 = 10,000 金。
- 1 金 = 100 银。
- 1 银 = 100 铜。
- 铜始终输出，砖、金、银为零时省略。

简中输出必须保持原来的无空格格式，例如：

```text
100020304 -> 1砖2金3银4铜
```

其他语言的显示规则：

- `zh-TW`：`1磚2金3銀4銅`。
- `en-US`：`1 brick 2 gold 3 silver 4 copper`。
- `vi`：`1 gạch 2 vàng 3 bạc 4 đồng`。

价格表和价格图从 `ui.item.currency` 读取单位。切换语言后图表可以重绘，但不得重新定义价格计算规则或改变价格请求。

回归测试：`tests/item-price-i18n.test.js`。

## 价格图加载

物品价格趋势是详情页默认展示内容，应保持同步组件 import。不要仅为拆包将其改成异步组件，否则会增加首次空白、独立 chunk 失败和无重试提示等线上不存在的路径。

## “主”徽标兼容

物品方案中的“主”徽标暂时保留现有 CSS `content: "主"`。当前组件属性不能可靠透传到最终 reference DOM，且英文和越南文在固定宽度内会溢出，因此不要直接替换成 `attr(data-primary-label)`。

只有在增加稳定的真实 DOM 包装、适配多语言宽度并完成视觉回归后，才能将该徽标完全迁移到 i18n。对应的 CSS allowlist 由 `tests/i18n.test.js` 精确限制在现有两处。
